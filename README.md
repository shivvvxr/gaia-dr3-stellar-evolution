# Gaia DR3 FLAME Stellar Mass vs Evolutionary Stage

Reproducibility package for:

> **Investigating FLAME-Inferred Stellar Mass and Evolutionary Stage in a Gaia DR3 Giant-Branch Population**

**Author:** Shivansh Ranjan Shrivastava  
**Analysis version:** 1.0.0  
**Date:** 2026-10-07

## Main result

The final FLAME-defined sample contains 1,399 stars selected from 9,974 matched Gaia sources using `490 <= evolstageFLAME < 890`, positive FLAME mass, and positive FLAME luminosity. The primary Spearman association is `rho = -0.361` with `p = 2.669e-44`, with a 5,000-resample bootstrap 95% interval of `[-0.414, -0.305]`. The mass distribution is best described by a three-component Gaussian mixture under BIC, while a two-component fit is retained as an interpretable sensitivity diagnostic.

The physical interpretation is deliberately limited: the study establishes a catalogue-level association and changing population composition, not an individual-star mass-loss rate.

## Canonical workflow

The reproducibility path is:

```text
Gaia TOP-10000 selection
        -> Gaia/FLAME parameter matching
        -> 9,974 matched Gaia/FLAME rows
        -> 1,399 primary sample
        -> bootstrap / sensitivity / GMM / permutation analyses
        -> published uncertainty propagation outputs
        -> manuscript figures and tables
```

Run the checked-in downstream analysis and verification with:

```bash
python -m pip install -r requirements.txt
python scripts/run_downstream_analysis.py
python scripts/verify_results.py
```

For the uncertainty propagation itself:

```bash
python scripts/propagate_mass_uncertainty.py --n-mc 5000
```

The optional `--full-gmm` flag refits the two-component GMM for every MC realization and is computationally expensive. The manuscript's final MC outputs are already archived under `results/uncertainty/`.

Data retrieval from Gaia requires internet access and `requirements-data-retrieval.txt`. The retrieval scripts are `retrieve_gaia_dataset.py`, `retrieve_matched_gaia_parameters.py`, and `retrieve_flame_mass_uncertainties.py`. The archived CSVs remain the authoritative inputs for reproducing the published analysis exactly.

## Reproducibility details

The downstream analysis uses master seed 42 and deterministic seed offsets for individual bootstrap, GMM, and permutation operations. The mass-uncertainty Monte Carlo uses seed 42. See `docs/REPRODUCIBILITY.md`.

The initial ADQL query intentionally has no `ORDER BY`. Therefore, the archived source-ID list is the authoritative record of the analysed subset.

## Figure policy

`paper/figures/` contains exact PNG snapshots extracted from the final submitted PDF. `results/downstream/figures/` contains figures regenerated by the canonical analysis code. The regenerated figures may differ slightly in typography or layout because of plotting-library versions, but they are tied to the same numerical outputs. See `docs/FIGURE_MAP.md`.
